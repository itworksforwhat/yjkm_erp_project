# 새로운 기능 사용 가이드

## 📋 개요

급여관리 ERP v2.0에 다음 기능들이 추가되었습니다:

1. ✅ **SECOM 출퇴근 시스템 연동** (기존 기능 활성화)
2. ✅ **Excel 직원 일괄 등록**
3. ✅ **근무 형태 변경 기능**
4. ✅ **2교대 주야간 스케줄 관리**

---

## 🔄 1. SECOM 연동 기능

### 사용 방법

1. **메인 메뉴** → **🔄 세콤 연동** 클릭

2. **ERP 서버설정 탭**에서 SECOM 데이터베이스 연결:
   - Provider 선택 (MS-SQL, MySQL, Oracle, ODBC)
   - SERVER IP 입력
   - PORT 입력
   - DB명.dbo 입력
   - USER 및 PASSWORD 입력
   - **접속확인** 버튼 클릭

3. **동기화 탭**에서 근태 데이터 가져오기:
   - 시작일자, 종료일자 설정
   - **🔄 근태 데이터 동기화** 버튼 클릭
   - 동기화 결과 확인

### 지원 기능

- **데이터베이스 연결**: MS-SQL, MySQL, Oracle, ODBC
- **CSV/JSON 파일 Import**: 파일 기반 출퇴근 데이터 가져오기
- **실시간 동기화**: 세콤 시스템과 실시간 근태 동기화
- **동기화 로그**: 동기화 이력 및 오류 추적

## 📥 2. Excel 직원 일괄 등록

### 템플릿 생성

1. **메인 메뉴** → **👥 직원 관리** 클릭
2. **📝 템플릿 생성** 버튼 클릭
3. 생성된 `직원_가져오기_템플릿.xlsx` 파일 확인

### Excel 파일 작성

템플릿 파일에는 2개의 시트가 있습니다:

#### 직원목록 시트
다음 항목을 입력하세요 (* 표시는 필수 항목):

| 항목 | 필수 | 예시 | 설명 |
|------|------|------|------|
| 직원코드* | ✓ | EMP001 | 고유한 직원 코드 |
| 이름* | ✓ | 홍길동 | 직원 이름 |
| 부서 |  | 생산팀 | 소속 부서 |
| 직급 |  | 대리 | 직급 |
| 입사일* | ✓ | 2024-01-15 | YYYY-MM-DD 형식 |
| 시급* | ✓ | 20000 | 시급 (원 단위) |
| 근무형태* | ✓ | 주간근무 (09:00~18:00) | 근무 스케줄 |
| 전화번호 |  | 010-1234-5678 | 연락처 |
| 이메일 |  | hong@company.com | 이메일 |
| 은행명 |  | KB국민은행 | 급여 계좌 은행 |
| 계좌번호 |  | 123-456-789 | 계좌번호 |
| 세콤직원ID |  | SECOM001 | 세콤 시스템 ID |
| 세콤카드번호 |  | CARD001 | 출퇴근 카드 번호 |
| 비고 |  | | 기타 메모 |

#### 작성가이드 시트
- 각 항목의 상세 설명 참고

### Excel 가져오기

1. **👥 직원 관리** 화면에서 **📥 Excel 가져오기** 클릭
2. 작성한 Excel 파일 선택
3. 가져오기 결과 확인
   - 성공: N명 직원 추가
   - 실패: 오류 메시지 표시 (중복 코드, 필수 항목 누락 등)

### Excel 내보내기

1. **👥 직원 관리** 화면에서 **📤 Excel 내보내기** 클릭
2. 저장 위치 및 파일명 지정
3. 현재 재직 중인 직원 목록이 Excel로 저장됨

### 주의사항

- **중복 코드**: 이미 존재하는 직원코드는 자동으로 건너뜁니다
- **날짜 형식**: 입사일은 YYYY-MM-DD 형식으로 입력
- **근무형태**: 시스템에 등록된 근무형태 이름과 정확히 일치해야 함

## ⚙️ 3. 근무 형태 설정

### 기본 제공 근무 형태

시스템에는 4가지 근무 형태가 사전 설정되어 있습니다:

1. **주간근무 (09:00~18:00)**
   - 일반적인 주간 근무
   - 휴게시간: 60분
   - 야간 근무: 아니오

2. **야간근무 (21:00~06:00)**
   - 야간 전담 근무
   - 휴게시간: 60분
   - 야간 근무: 예 (22:00~06:00)

3. **2교대(주간) (06:00~18:00)**
   - 2교대 주간 근무
   - 휴게시간: 60분
   - 야간 근무: 아니오

4. **2교대(야간) (18:00~06:00)**
   - 2교대 야간 근무
   - 휴게시간: 60분
   - 야간 근무: 예 (22:00~06:00)

### 근무 형태 관리

1. **메인 메뉴** → **🔧 근무 설정** 클릭
2. 근무 스케줄 조회 및 수정
3. 새로운 근무 형태 추가 가능

### 직원에게 근무 형태 할당

#### 방법 1: 개별 할당
1. **👥 직원 관리** → 직원 추가/수정
2. **근무 형태** 드롭다운에서 선택
3. 저장

#### 방법 2: Excel 일괄 할당
1. Excel 템플릿에서 **근무형태** 열에 원하는 근무형태 입력
2. Excel 가져오기로 일괄 등록

## 🔄 4. 2교대 주야간 스케줄 관리

### 개요

2교대 근무는 주간 근무와 야간 근무를 일정 주기(기본 2주)로 교대하는 방식입니다.

### 교대 스케줄 할당

1. **메인 메뉴** → **🔄 교대 관리** 클릭

2. **교대 근무 현황** 확인
   - 총 직원 수
   - 현재 주간/야간 근무자 수
   - 고정 근무자 수

3. **2교대 스케줄 할당**
   - 할당할 직원 선택 (체크박스 클릭)
   - 시작일 설정 (예: 2026-01-01)
   - 교대 주기 설정 (기본: 2주)
   - **✅ 2교대 스케줄 할당** 버튼 클릭

### 교대 스케줄 동작 방식

#### 2주 교대 예시

- **1~2주차**: 주간 근무 (06:00~18:00)
- **3~4주차**: 야간 근무 (18:00~06:00)
- **5~6주차**: 주간 근무 (06:00~18:00)
- ... 반복

#### 자동 스케줄링

- 시스템이 자동으로 각 날짜의 근무 형태를 계산
- 근태 입력 시 해당일의 근무 형태 자동 적용
- 급여 계산 시 야간 수당 자동 반영

### 일괄 할당 규칙

여러 직원을 선택하여 일괄 할당하면:
- 짝수 번째 직원: 주간 근무부터 시작
- 홀수 번째 직원: 야간 근무부터 시작
- 자동으로 주야간 균형 유지

### 월간 스케줄 확인

교대 근무 관리 화면에서 현재 월의 주야간 분포를 확인할 수 있습니다.

## 🎯 사용 시나리오

### 시나리오 1: 신규 직원 대량 등록

1. **📝 템플릿 생성** 버튼으로 Excel 템플릿 다운로드
2. Excel에 50명의 직원 정보 입력
3. 근무형태 열에 "2교대(주간)" 또는 "2교대(야간)" 입력
4. **📥 Excel 가져오기**로 일괄 등록
5. **🔄 교대 관리**에서 2교대 스케줄 할당

### 시나리오 2: SECOM 출퇴근 데이터 연동

1. **🔄 세콤 연동** 메뉴 접속
2. SECOM 서버 정보 입력 및 접속 확인
3. 기간 설정 (예: 2026-01-01 ~ 2026-01-31)
4. **근태 데이터 동기화** 실행
5. 동기화 로그 확인
6. **💰 급여 계산**에서 자동 반영 확인

### 시나리오 3: 교대 근무 전환

기존 주간 근무 직원 10명을 2교대로 전환:

1. **🔄 교대 관리** 메뉴 접속
2. 전환할 10명의 직원 선택
3. 시작일: 다음 달 1일
4. 교대 주기: 2주
5. **스케줄 할당** 실행
6. 시스템이 자동으로 주야간 교대 시작

```
1. 직원 등록
   Excel → Excel 가져오기 → 직원 DB 저장 → 연차 자동 초기화

2. SECOM 연동
   SECOM DB → 근태 동기화 → 근태 DB 저장 → 근무시간 자동 계산

3. 교대 근무
   교대 스케줄 할당 → 직원별 메타데이터 저장 → 날짜별 자동 계산

4. 급여 계산
   근태 데이터 → 근무형태별 시간 계산 → 야간/잔업 수당 → 급여 확정
```

## ⚠️ 주의사항

### Excel 가져오기

- Excel 파일은 `.xlsx` 형식 권장
- 시트 이름은 반드시 "직원목록"이어야 함
- 중복된 직원코드는 자동으로 건너뛰므로 오류 메시지 확인 필수

### SECOM 연동

- SECOM 데이터베이스 접근 권한 필요
- 방화벽 설정 확인 (서버 IP 및 PORT 접근 가능 여부)
- 세콤 직원 ID 또는 카드번호가 ERP 시스템에 사전 등록되어 있어야 매칭됨

### 교대 근무

- 교대 스케줄 할당 전 직원의 기본 근무형태 확인
- 시작일은 가급적 월 초(1일)로 설정 권장
- 교대 주기 변경 시 기존 근태 데이터 재계산 필요 없음 (향후 적용)

## 🔧 문제 해결

### Excel 가져오기 실패

**증상**: "Excel 파일 읽기 오류"
**해결**:
- 파일이 열려있지 않은지 확인
- .xlsx 형식인지 확인
- 시트 이름이 "직원목록"인지 확인

**증상**: "중복된 직원코드"
**해결**:
- 기존 직원 목록에서 코드 중복 확인
- 직원코드 변경 후 재시도

### SECOM 연동 실패

**증상**: "연결 실패"
**해결**:
- SERVER IP, PORT 정보 재확인
- 방화벽 설정 확인
- 데이터베이스 서버 실행 상태 확인

**증상**: "직원 없음" 오류
**해결**:
- 직원 추가 시 세콤 직원ID 또는 카드번호 입력
- SECOM 데이터의 직원 코드와 ERP 직원코드 일치 확인

### 교대 스케줄 오류

**증상**: 교대 스케줄이 제대로 적용되지 않음
**해결**:
- 시작일 확인
- 교대 주기 확인 (2, 3, 4주 등)
- 근무형태가 "2교대(주간)" 또는 "2교대(야간)"인지 확인
