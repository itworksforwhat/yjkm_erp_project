# TXT/CSV 파일로 직원 등록 가이드

## 🎯 개요

Excel 외에도 **TXT, CSV, TSV** 파일로 직원 정보를 가져올 수 있습니다.
텍스트 파일로 작성하거나 다른 시스템에서 내보낸 CSV 파일을 바로 가져올 수 있어 편리합니다.

---

## 📋 지원 파일 형식

| 형식 | 확장자 | 구분자 | 설명 |
|------|--------|--------|------|
| CSV | .csv | 쉼표(,) | 쉼표로 구분된 값 |
| TXT | .txt | 탭 또는 쉼표 | 탭 우선, 쉼표 대체 |
| TSV | .tsv | 탭 | 탭으로 구분된 값 |

**자동 감지:** 프로그램이 파일 형식을 자동으로 인식합니다.

---

## ⚡ 빠른 시작

### 1단계: TXT 파일 생성

#### 방법 1: 메모장으로 직접 작성

1. 메모장 실행
2. 첫 줄에 **열 제목** 입력 (탭 또는 쉼표로 구분)
3. 다음 줄부터 직원 정보 입력
4. `.txt` 또는 `.csv`로 저장

#### 방법 2: Excel에서 TXT로 저장

1. Excel에서 직원 정보 작성
2. **파일 → 다른 이름으로 저장**
3. 파일 형식: **텍스트(탭으로 분리)** 또는 **CSV(쉼표로 분리)** 선택
4. 저장

### 2단계: 파일 가져오기

1. 프로그램 실행
2. **👥 직원 관리** 메뉴
3. **📥 파일 가져오기** 버튼
4. TXT 또는 CSV 파일 선택
5. 완료!

## 📝 파일 형식 예시

### CSV 파일 (.csv)

쉼표로 구분:
```csv
직원코드*,이름*,부서,직급,입사일*,시급*,근무형태*,전화번호,이메일
EMP001,홍길동,생산1팀,대리,2024-01-15,20000,주간근무 (09:00~18:00),010-1234-5678,hong@company.com
EMP002,김철수,생산1팀,사원,2024-02-01,22000,2교대(주간) (06:00~18:00),010-2345-6789,kim@company.com
EMP003,이영희,관리팀,과장,2024-03-10,18000,주간근무 (09:00~18:00),010-3456-7890,lee@company.com
```

### TXT 파일 (.txt) - 탭 구분

탭(Tab 키)으로 구분:
```
직원코드*	이름*	부서	직급	입사일*	시급*	근무형태*	전화번호	이메일
EMP001	홍길동	생산1팀	대리	2024-01-15	20000	주간근무 (09:00~18:00)	010-1234-5678	hong@company.com
EMP002	김철수	생산1팀	사원	2024-02-01	22000	2교대(주간) (06:00~18:00)	010-2345-6789	kim@company.com
EMP003	이영희	관리팀	과장	2024-03-10	18000	주간근무 (09:00~18:00)	010-3456-7890	lee@company.com
```

### TXT 파일 (.txt) - 쉼표 구분

CSV와 동일하게 쉼표 사용 가능:
```
직원코드*,이름*,입사일*,시급*,근무형태*
EMP101,김민수,2024-01-10,19000,주간근무 (09:00~18:00)
EMP102,박지영,2024-01-15,21000,주간근무 (09:00~18:00)
EMP103,최준호,2024-02-01,20000,2교대(주간) (06:00~18:00)
```

## 📋 필수 열 (컬럼)

TXT/CSV 파일에 **반드시 포함**해야 하는 열:

| 열 이름 | 필수 | 형식 | 예시 |
|---------|------|------|------|
| 직원코드* | ✓ | 영문+숫자 | EMP001 |
| 이름* | ✓ | 한글/영문 | 홍길동 |
| 입사일* | ✓ | YYYY-MM-DD | 2024-01-15 |
| 시급* | ✓ | 숫자만 | 20000 |
| 근무형태* | ✓ | 정확한 이름 | 주간근무 (09:00~18:00) |

**선택 열:** 부서, 직급, 전화번호, 이메일, 은행명, 계좌번호, 세콤직원ID, 세콤카드번호, 비고

## ❌ 흔한 오류

### 오류 1: 구분자 혼용

```
❌ 잘못됨:
직원코드*,이름*	입사일*,시급*
EMP001,홍길동	2024-01-15,20000

✅ 올바름 (쉼표 또는 탭 중 하나만):
직원코드*,이름*,입사일*,시급*
EMP001,홍길동,2024-01-15,20000
```

### 오류 2: 열 제목 누락

```
❌ 잘못됨 (첫 줄에 제목 없음):
EMP001,홍길동,2024-01-15,20000

✅ 올바름:
직원코드*,이름*,입사일*,시급*
EMP001,홍길동,2024-01-15,20000
```

### 오류 3: 데이터 내 쉼표

데이터에 쉼표가 포함된 경우 **큰따옴표**로 감싸기:
```csv
직원코드*,이름*,비고
EMP001,홍길동,"생산팀, 교대근무 가능"
```

### 오류 4: 인코딩 문제

한글이 깨지면:
1. 메모장에서 **다른 이름으로 저장**
2. 인코딩: **UTF-8** 선택
3. 저장

## 🔄 Excel과 TXT/CSV 비교

| 기능 | Excel | TXT/CSV |
|------|-------|---------|
| 편집 용이성 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| 파일 크기 | 큼 | 작음 |
| 호환성 | Excel 필요 | 모든 시스템 |
| 작성 속도 | 중간 | 빠름 (직접 입력 시) |
| 템플릿 | ✅ 제공 | ✅ 간단 |
| 가이드 포함 | ✅ 별도 시트 | ❌ |

**추천:**
- **Excel:** 많은 직원, 복잡한 정보
- **TXT/CSV:** 적은 직원, 간단한 정보, 타 시스템 연동

## 💡 사용 팁

### Tip 1: Excel에서 CSV로 변환

```
1. Excel 파일 열기
2. 파일 → 다른 이름으로 저장
3. CSV UTF-8(쉼표로 분리) 선택
4. 저장
5. 프로그램에서 가져오기
```

### Tip 2: 구글 스프레드시트 활용

```
1. 구글 스프레드시트에서 작성
2. 파일 → 다운로드 → CSV
3. 프로그램에서 가져오기
```

### Tip 3: 타 시스템 데이터 활용

```
다른 ERP/인사 시스템에서 CSV 내보내기
→ 열 이름만 맞춰서 편집
→ 바로 가져오기 가능
```

### Tip 4: 대량 직원 등록

```
메모장/에디터로 빠르게 입력:
1. 첫 줄: 열 제목 복사
2. 각 줄에 직원 정보 입력
3. 탭 키로 구분
4. 저장 후 가져오기
```

## 🔧 문제 해결

### 오류 1: "파일을 읽을 수 없습니다"

**원인:**
- 파일이 다른 프로그램에서 열려있음
- 파일 형식이 잘못됨

**해결:**
1. 파일 닫기
2. 파일 확장자 확인 (.txt, .csv)
3. 메모장으로 열어서 내용 확인

### 오류 2: "한글이 깨집니다"

**원인:** 인코딩 문제

**해결:**
1. 메모장에서 열기
2. 다른 이름으로 저장
3. 인코딩: **UTF-8** 선택
4. 저장

### 오류 3: "필수 항목 누락"

**원인:** 필수 열이 없거나 빈 값

**해결:**
1. 열 제목에 `직원코드*`, `이름*`, `입사일*`, `시급*`, `근무형태*` 있는지 확인
2. 모든 행에 필수 항목 입력되었는지 확인
3. 빈 줄 제거

### 오류 4: "데이터 파싱 오류"

**원인:** 구분자 혼용 또는 잘못된 형식

**해결:**
1. 쉼표 또는 탭 **하나만** 사용
2. 데이터에 구분자가 포함되면 큰따옴표로 감싸기
3. 각 행의 열 개수가 동일한지 확인
