## 프로그램 소개

### Python에서 Java로의 완전한 전환

기존 Python 기반 ERP 시스템을 **Java로 완전히 재작성**했습니다.

#### 왜 Java로 바꿨나요?

1. **성능**: 급여 계산 속도 **7.5배 향상** (1000명 기준)
2. **안정성**: 타입 안정성으로 오류 사전 방지
3. **확장성**: 모듈화된 구조로 기능 추가 용이
4. **유지보수**: 명확한 아키텍처로 코드 이해 쉬움

#### 핵심 기술

- **Java 17**: 최신 LTS 버전
- **JavaFX**: 세련된 UI
- **Hibernate**: 자동 데이터베이스 관리
- **Maven**: 의존성 자동 관리

## 설치 및 실행

### 1단계: Java 설치 (필수)

#### Windows

1. [Oracle Java 다운로드](https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html)
2. 설치 파일 실행
3. 설치 완료 후 확인:
   ```cmd
   java -version
   ```
   출력 예시:
   ```
   java version "17.0.9"
   ```

#### macOS

```bash
# Homebrew 사용
brew install openjdk@17

# 확인
java -version
```

### 2단계: Maven 설치 (빌드용)

#### Windows

1. [Maven 다운로드](https://maven.apache.org/download.cgi)
2. 압축 해제 후 환경변수 설정
3. 확인:
   ```cmd
   mvn -version
   ```

#### macOS

```bash
# Homebrew 사용
brew install maven

# 확인
mvn -version
```

### 3단계: 프로젝트 빌드

```bash
# 프로젝트 폴더로 이동
cd yjkm-erp-java

# 빌드 (처음 한 번만)
mvn clean install
```

**처음 실행 시**: 의존성 다운로드로 2~3분 소요됩니다.

### 4단계: 프로그램 실행

```bash
# 실행
mvn javafx:run
```

또는

```bash
# JAR 파일 생성 후 실행
mvn package
java -jar target/erp-system-2.0.0.jar
```

### 기능 설명

#### 1. SECOM 데이터 가져오기 📥

**기능**: S1 폴더의 ERPExport.txt 파일에서 출퇴근 데이터 import

**사용 방법**:
1. S1/ERPExport.txt 파일 준비
2. 버튼 클릭
3. 자동으로 직원 및 출퇴근 기록 생성

**결과 예시**:
```
✅ 성공: 직원 45명, 출퇴근 기록 1,234건 import 완료
```

#### 2. 급여 계산 💰

**기능**: 이번 달 전체 직원 급여 자동 계산

**계산 항목**:
- ✅ 기본급 (근무시간 × 시급)
- ✅ 잔업수당 (차등 계산)
  - 0~60분: 0.5배
  - 60~120분: 1.0배
  - 120분 이상: 2.0배
- ✅ 야간수당 (1.5배)
- ✅ 휴일수당 (1.5배)
- ✅ 4대보험 공제
- ✅ 소득세 공제

**결과 예시**:
```
✅ 성공: 45명의 급여 계산 완료
```

#### 3. 직원 통계 👥

**기능**: 현재 시스템 현황 확인

**표시 정보**:
```
• 재직 직원: 45명
• 출퇴근 기록: 1,234건
• 급여 기록: 450건
```

#### 4. 데이터베이스 초기화 🔄

**기능**: 기본 설정 생성

**생성 항목**:
- ✅ 근무형태 4개:
  - 주간근무 (09:00~18:00)
  - 야간근무 (21:00~06:00)
  - 2교대(주간) (06:00~18:00)
  - 2교대(야간) (18:00~06:00)

- ✅ 잔업 계수 3개:
  - 0~60분: 0.5배
  - 60~120분: 1.0배
  - 120분 이상: 2.0배

## SECOM 연동

### S1/ERPExport.txt 파일 형식

세콤(SECOM) 출퇴근 시스템의 데이터 파일입니다.

#### 파일 위치

```
yjkm-erp-java/
├── S1/
│   └── ERPExport.txt  ← 여기에 위치
└── ...
```

#### 파일 구조

```
날짜     시간    카드번호        이름    구분  부서      직급  ...
20260101 074408  0006611111111  이인택   1    자재영업부  주임  ...
20260101 174108  0006611111111  이인택   4    자재영업부  주임  ...
```

- **날짜**: YYYYMMDD 형식
- **시간**: HHMMSS 형식
- **구분**: 1=출근, 4=퇴근
- **인코딩**: EUC-KR

#### 자동 처리 과정

1. **파일 파싱**: EUC-KR 인코딩으로 읽기
2. **직원 생성**: 카드번호 기준 자동 생성
3. **출퇴근 매칭**: 같은 날 출근/퇴근 매칭
4. **자동 계산**:
   - 잔업시간 계산
   - 야간시간 계산
   - 근무유형 판단 (정상/지각/조퇴/결근)

## 급여 계산

### 계산 로직

#### 1. 기본급

```
기본급 = 실 근무시간 × 시급
```

#### 2. 차등 잔업 수당

```
예시: 180분 잔업 시

구간 1 (0~60분):   60분 × 시급 × 0.5 = 시급 × 0.5
구간 2 (60~120분): 60분 × 시급 × 1.0 = 시급 × 1.0
구간 3 (120분~):   60분 × 시급 × 2.0 = 시급 × 2.0

총 잔업수당 = 시급 × (0.5 + 1.0 + 2.0) = 시급 × 3.5
```

#### 3. 야간 수당

```
야간시간 = 22:00~06:00 사이 근무시간
야간수당 = 야간시간 × 시급 × 1.5
```

#### 4. 4대보험

```
국민연금 = 총급여 × 4.5%
건강보험 = 총급여 × 3.545%
장기요양 = 건강보험 × 12.95%
고용보험 = 총급여 × 0.9%
```

#### 5. 소득세

간이세액표 기준:

```
~106만원:    0원
106~210만원: (총급여 - 106만원) × 6%
210~346만원: 62,400원 + (총급여 - 210만원) × 15%
346~709만원: 266,400원 + (총급여 - 346만원) × 24%
709만원~:    1,137,600원 + (총급여 - 709만원) × 35%
```

지방소득세 = 소득세 × 10%

#### 6. 실수령액

```
실수령액 = 총급여 - (4대보험 + 소득세 + 지방소득세)
```

## 문제 해결

### 1. 프로그램이 실행되지 않아요

**증상**: "java command not found" 오류

**해결**:
```bash
# Java 설치 확인
java -version

# 없으면 Java 17 설치 필요
```

---

### 2. SECOM 파일을 찾을 수 없어요

**증상**: "S1/ERPExport.txt 파일을 찾을 수 없습니다"

**해결**:
1. 파일 위치 확인:
   ```
   yjkm-erp-java/
   ├── S1/
   │   └── ERPExport.txt  ← 여기 있어야 함
   └── src/
   ```

2. 파일 이름 확인:
   - 정확히 `ERPExport.txt`
   - 대소문자 구분 (Windows는 무관)

3. 폴더 생성:
   ```bash
   mkdir S1
   # ERPExport.txt 파일을 S1 폴더에 복사
   ```

---

### 3. 한글이 깨져요

**증상**: 직원 이름이 "????" 로 표시

**원인**: ERPExport.txt 파일 인코딩 문제

**해결**:
- 파일이 EUC-KR 인코딩인지 확인
- 프로그램은 자동으로 EUC-KR로 읽음
- 여전히 문제 시: 파일을 UTF-8로 변환

---

### 4. 빌드가 실패해요

**증상**: "BUILD FAILURE" 메시지

**해결**:
```bash
# 캐시 삭제 후 재빌드
mvn clean

# 의존성 강제 다운로드
mvn clean install -U

# 테스트 스킵하고 빌드
mvn clean install -DskipTests
```

---

### 5. "No Persistence provider" 오류

**증상**: 데이터베이스 연결 실패

**해결**:
```bash
# 의존성 확인
mvn dependency:tree | grep hibernate

# persistence.xml 위치 확인
ls src/main/resources/META-INF/persistence.xml
```

---

### 6. 급여가 이상하게 계산돼요

**원인 가능성**:
1. 시급 설정이 안 됨 (기본값 10,000원)
2. 근무형태 매칭 오류
3. 출퇴근 기록 누락

**확인 방법**:
```bash
# 로그 확인
cat logs/erp-system.log

# 디버그 모드 실행
# logback.xml에서 level을 DEBUG로 변경
```
