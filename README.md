# 💼 급여관리 ERP v2.0 - Complete Edition

## 🎯 개요

완전한 기능을 갖춘 전문가급 급여관리 시스템입니다.
근무시간 자유 설정, 차등 잔업 수당, 연차 자동 관리, 세콤 연동 등 모든 기능이 구현되어 있습니다.

## ✨ 주요 기능

### 1. 직원 관리
- ✅ 직원 추가/조회
- ✅ 근무 형태 개별 할당
- ✅ 자동 연차 부여

### 2. 근무 시간 관리
- ✅ 근무 형태 자유 추가/수정
- ✅ 시작/종료 시간 자유 설정
- ✅ 야간 시간대 설정
- ✅ DB 영구 저장

### 3. 잔업 수당
- ✅ 시간대별 차등 수당
- ✅ 구간별 배율 자유 설정
- ✅ 무제한 구간 추가

### 4. 휴가 관리
- ✅ 연차 자동 계산 (근속년수 기반)
- ✅ 반차/병가/특별휴가
- ✅ 휴가 신청/승인
- ✅ 자동 연차 차감

### 5. 급여 계산
- ✅ 월별 일괄 계산
- ✅ 차등 잔업 수당 자동 적용
- ✅ 4대보험 자동 계산
- ✅ 상세 명세서

### 6. 세콤 연동
- ✅ CSV/JSON Import
- ✅ 자동 근태 생성
- ✅ 동기화 로그

## 📦 설치 방법

### 1. Python 설치
Python 3.8 이상 필요

### 2. 패키지 설치
```bash
pip install customtkinter pillow pandas openpyxl reportlab
```

### 3. 시스템 초기화 (최초 1회)
```bash
python init_system_v2.py
```

### 4. 프로그램 실행
```bash
python main.py
```

## 📖 사용 가이드

### 근무 시간 설정
1. "🔧 근무 설정" 메뉴 클릭
2. "➕ 새 근무 형태 추가" 클릭
3. 시간 입력 (예: 14:00~23:00)
4. 저장

### 직원 추가
1. "👥 직원 관리" 메뉴 클릭
2. "➕ 직원 추가" 버튼 클릭
3. 정보 입력
4. 근무 형태 선택 (드롭다운)
5. 저장

### 급여 계산
1. "💰 급여 계산" 메뉴 클릭
2. 년/월 선택
3. "전체 직원 계산" 버튼 클릭
4. 완료!

### 상세 명세서 확인
1. 급여 목록에서 직원 더블클릭
2. 상세 명세서 확인

## 🎯 핵심 기능 상세

### 차등 잔업 수당
```
기본 설정:
- 0~60분: 0.5배
- 60~120분: 1.0배
- 120분 이상: 2.0배

변경 가능:
1. "💸 잔업 설정" 메뉴
2. 구간 더블클릭
3. 배율 수정
4. 저장 → 즉시 적용!
```

### 연차 자동 계산
```
근속 기간별:
- 6개월: 6일 (월차)
- 1년: 15일
- 3년: 16일
- 11년 이상: 최대 25일

자동 처리:
- 직원 추가 시 자동 계산
- 휴가 승인 시 자동 차감
```

## 💡 Tips

### 직원 정보 입력 시
- 직원코드는 고유해야 합니다
- 시급은 숫자만 입력
- 근무 형태는 드롭다운에서 선택

### 급여 계산 시
- 월말에 한 번만 계산
- 계산 전 근태 확인 필수
- 명세서는 더블클릭으로 확인

### 설정 변경 시
- 근무 시간 변경은 즉시 적용
- 잔업 계수 변경은 다음 계산부터
- 모든 설정은 DB에 영구 저장
