# Excel로 직원 일괄 등록 가이드

## 🎯 개요

이 시스템은 Excel 파일로 여러 명의 직원을 한 번에 등록할 수 있습니다.
수십 명의 직원을 수작업으로 입력하는 대신, Excel에 정리한 후 한 번에 가져올 수 있습니다.

---

## ⚡ 빠른 시작 (3단계)

### 1단계: 필수 패키지 설치 (처음 한 번만)

CMD 또는 PowerShell에서:
```bash
pip install pandas openpyxl
```

### 2단계: 템플릿 생성

1. 프로그램 실행
2. **👥 직원 관리** 메뉴 클릭
3. **📝 템플릿 생성** 버튼 클릭
4. `직원_가져오기_템플릿.xlsx` 파일이 생성됨

### 3단계: 직원 정보 입력 후 가져오기

1. 생성된 Excel 파일 열기
2. 직원 정보 입력
3. 프로그램에서 **📥 Excel 가져오기** 클릭
4. 입력한 Excel 파일 선택
5. 완료!

---

## 📋 Excel 템플릿 구조

템플릿에는 **2개의 시트**가 있습니다:

### 시트 1: 직원목록 (여기에 입력)

| 열 이름 | 필수 | 예시 | 설명 |
|---------|------|------|------|
| 직원코드* | ✓ | EMP001 | 중복 불가능한 고유 코드 |
| 이름* | ✓ | 홍길동 | 직원 이름 |
| 부서 | | 생산팀 | 소속 부서 |
| 직급 | | 대리 | 직급 (사원, 대리, 과장 등) |
| 입사일* | ✓ | 2024-01-15 | YYYY-MM-DD 형식 |
| 시급* | ✓ | 20000 | 숫자만 입력 (단위: 원) |
| 근무형태* | ✓ | 주간근무 (09:00~18:00) | 드롭다운에서 선택 |
| 전화번호 | | 010-1234-5678 | 연락처 |
| 이메일 | | hong@company.com | 이메일 주소 |
| 은행명 | | KB국민은행 | 급여 계좌 은행 |
| 계좌번호 | | 123-456-789 | 계좌번호 |
| 세콤직원ID | | SECOM001 | 세콤 시스템 ID |
| 세콤카드번호 | | CARD001 | 출퇴근 카드 번호 |
| 비고 | | | 기타 메모 |

**\* 표시는 필수 항목**

### 시트 2: 작성가이드 (참고용)

각 항목의 상세 설명과 주의사항이 있습니다.

## 📝 Excel 작성 요령

### ✅ 올바른 예시

```
직원코드*    이름*     부서      입사일*        시급*    근무형태*
EMP001      홍길동    생산1팀   2024-01-15    20000    주간근무 (09:00~18:00)
EMP002      김철수    생산1팀   2024-02-01    22000    2교대(주간) (06:00~18:00)
EMP003      이영희    관리팀    2024-03-10    18000    주간근무 (09:00~18:00)
```

### ❌ 잘못된 예시와 해결 방법

**문제 1: 입사일 형식 오류**
```
❌ 잘못됨: 2024/01/15, 2024.1.15, 24-01-15
✅ 올바름: 2024-01-15
```

**문제 2: 시급에 쉼표나 단위 포함**
```
❌ 잘못됨: 20,000원, 20000원, 2만원
✅ 올바름: 20000
```

**문제 3: 근무형태 이름 불일치**
```
❌ 잘못됨: 주간, 낮근무, 일반근무
✅ 올바름: 주간근무 (09:00~18:00)
```
→ 정확한 이름은 템플릿의 작성가이드 참조

**문제 4: 직원코드 중복**
```
❌ EMP001이 두 번 나옴
✅ 각 직원마다 고유한 코드 사용 (EMP001, EMP002, EMP003...)
```

## 🎯 근무형태 선택 가이드

시스템에 기본으로 등록된 근무형태:

### 1. 주간근무 (09:00~18:00)
- 일반적인 사무직, 관리직
- 월~금 근무
- 휴게시간: 60분

### 2. 야간근무 (21:00~06:00)
- 야간 전담 근무
- 야간 수당 자동 적용
- 휴게시간: 60분

### 3. 2교대(주간) (06:00~18:00)
- 2교대 주간 조
- 2주마다 야간과 교대
- 휴게시간: 60분

### 4. 2교대(야간) (18:00~06:00)
- 2교대 야간 조
- 2주마다 주간과 교대
- 야간 수당 자동 적용
- 휴게시간: 60분

**주의:** Excel에 입력할 때는 괄호와 시간까지 **정확히** 입력하세요.

## 🔧 문제 해결

### 오류 1: "pandas를 찾을 수 없습니다"

**원인:** 필요한 패키지가 설치되지 않음

**해결:**
```bash
pip install pandas openpyxl
```

### 오류 2: "Excel 파일을 읽을 수 없습니다"

**원인:**
- Excel 파일이 열려있음
- 파일 형식이 `.xlsx`가 아님
- 시트 이름이 "직원목록"이 아님

**해결:**
1. Excel 파일 닫기
2. `.xlsx` 형식으로 저장
3. 첫 번째 시트 이름을 "직원목록"으로 변경

### 오류 3: "필수 항목 누락"

**원인:** 직원코드, 이름, 입사일, 시급, 근무형태 중 하나가 빈칸

**해결:**
- 모든 필수 항목(\* 표시)을 입력했는지 확인
- 공백이나 빈 셀이 없는지 확인

### 오류 4: "중복된 직원코드"

**원인:**
- Excel에 같은 직원코드가 여러 번 있음
- 이미 등록된 직원코드를 다시 사용

**해결:**
- Excel에서 직원코드 중복 제거
- 새로운 고유 코드 사용
- 기본적으로 중복은 자동으로 건너뛰므로 참고용 오류 메시지임

### 오류 5: "알 수 없는 근무형태"

**원인:** 근무형태 이름이 시스템에 등록된 이름과 다름

**해결:**
- 템플릿의 작성가이드에서 정확한 이름 확인
- 괄호와 시간까지 정확히 입력
- 예: "주간근무 (09:00~18:00)"

## 📊 대량 등록 시나리오

### 시나리오 1: 신입 사원 50명 등록

```
1. 📝 템플릿 생성
2. Excel에서 50명 정보 입력
   - 직원코드: NEW001 ~ NEW050
   - 근무형태: 모두 "주간근무 (09:00~18:00)"
   - 시급: 각자 다름
3. 📥 Excel 가져오기
4. 결과: ✅ 50명 추가 완료
5. 자동 처리:
   - 연차 15일 자동 부여 (입사일 기준)
   - 휴가 잔여일수 초기화
```

### 시나리오 2: 2교대 근무자 30명 등록

```
1. 📝 템플릿 생성
2. Excel에서 30명 정보 입력
   - 직원코드: SHIFT001 ~ SHIFT030
   - 근무형태:
     * 15명 → "2교대(주간) (06:00~18:00)"
     * 15명 → "2교대(야간) (18:00~06:00)"
   - 세콤직원ID: 각자의 세콤 ID 입력
   - 세콤카드번호: 각자의 카드번호 입력
3. 📥 Excel 가져오기
4. 결과: ✅ 30명 추가 완료
5. 추가 작업:
   - 🔄 교대 관리 메뉴에서 2교대 스케줄 할당
```

## 📤 Excel 내보내기

### 현재 직원 목록을 Excel로 저장하기

1. **👥 직원 관리** 메뉴
2. **📤 Excel 내보내기** 버튼
3. 저장 위치 선택
4. 완료!

### 활용 방법

**용도 1: 백업**
```
정기적으로 직원 목록을 Excel로 저장하여 백업
권장 주기: 매월 1회
```

**용도 2: 데이터 분석**
```
Excel로 내보낸 후:
- 부서별 인원 분석
- 근무형태별 통계
- 시급 분포 확인
- 피벗 테이블 작성
```

**용도 3: 타 시스템 연동**
```
Excel 형식으로 내보내서:
- 회계 시스템에 전달
- 인사 관리 시스템에 입력
- 경영진 보고용 자료 작성
```
